#### ✦ ` features ` ✦

* **3D blooming animation** — curved green stems shoot up from the knot while sculpted spiral roses unfurl outward with mini ASCII firework bursts.
* **slow 3D showcase spin** — smoothly rotates in 3D perspective with depth shading once bloomed.
* **pink braille ribbon** — custom pink Unicode braille bow tied right at the base of the wrapper.
* **ambient ASCII particles** — floating `<3` hearts, multi-line ASCII hearts, and twinkling sparkles drifting around the bouquet.
* **mascot & typewriter message** — cute ASCII character at the bottom paired with a letter-by-letter reveal caption.
* **zero-dependency & responsive** — scales automatically across desktop **and** mobile screens with no external libraries required.

#### 💥 ` getting started ` 💥

you don't need Node.js, npm, or any build tools. only need just a browser.

* **option 1 — view live (easiest):**
  open **[(https://qyjyqqq.github.io/ascii-bouquet/](https://github.io)** directly in any desktop or mobile browser.

* **option 2 — download & run on your computer:**
  1. click the green **`<> Code`** button at the top of this page and select **Download ZIP**.
  2. extract the downloaded ZIP folder.
  3. open the folder and double-click **`index.html`** to launch it in your browser.

* **option 3:**
  1. **download the code:**
     ```bash
     git clone https://github.com/qyjyqqq/ascii-bouquet
     ```
  2. **open the folder:**
     ```bash
     cd ascii-bouquet
     ```
  3. **launch it:**
     double-click **`index.html`** to open it directly in your browser.

#### 🛠️ ` tech stack ` 🛠️

* **HTML5 (`<canvas>`)** — 2D rendering surface for sub-pixel ASCII text projection
* **CSS3** — responsive viewport sizing and radial background gradient
* **Vanilla JavaScript (ES6)** — 3D Y-axis/X-axis rotation matrices, Bezier stem curves, Z-depth sorting, and particle physics
* **GitHub Pages** — web hosting
